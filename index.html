🎵 Concertagenda — Setup

Eenmalige setup: maak een gratis Supabase-project aan. Je concerten en tickets worden dan gesynchroniseerd op al je toestellen.

1
Maak een gratis account aan
Ga naar supabase.com → "Start your project" → log in met GitHub.
2
Nieuw project aanmaken
Klik "New project" → kies een naam (bv. concertagenda) → kies een regio dicht bij België (Frankfurt) → klik "Create new project".
3
Tabel aanmaken
Ga naar SQL Editor in je project en voer dit uit:
create table if not exists store ( key text primary key, value jsonb not null default '[]'::jsonb ); alter table store disable row level security;
4
Storage bucket aanmaken
Ga naar Storage → "New bucket" → naam: tickets → zet "Public bucket" aan → klik "Save".
5
Je project-URL en sleutel ophalen
Ga naar Project Settings → API. Kopieer de "Project URL" en de "anon public" sleutel hieronder.
